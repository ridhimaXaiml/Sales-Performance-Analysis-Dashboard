# 📊 Sales Performance Analytics Dashboard – Power BI

## 🚀 Project Overview

The **Sales Performance Analytics Dashboard** is an interactive Power BI dashboard designed to analyse sales performance, revenue trends, product performance, customer behaviour, and regional sales insights.

The dashboard transforms raw sales data into meaningful visual insights that help businesses monitor key performance indicators (KPIs), identify trends, and make data-driven decisions.

## 🛠️ Tools & Technologies

* **Power BI Desktop** – Dashboard development and data visualisation
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and calculated metrics
* **Data Modelling** – Relationships and structured data analysis

## 📌 Key KPIs

The dashboard provides an overview of important business metrics, including:

* 💰 Total Sales
* 📦 Total Orders
* 🛍️ Total Quantity Sold
* 📈 Sales Growth
* 👥 Customer Performance
* 🏆 Top-Performing Products
* 🌍 Regional/Geographical Performance

## 📊 Dashboard Features

### 1. Sales Overview

Provides a high-level summary of overall business performance and key sales metrics.

### 2. Sales Trend Analysis

Shows how sales change over time and helps identify seasonal patterns and growth trends.

### 3. Product Performance

Identifies top-performing and underperforming products based on sales and quantity.

### 4. Customer Analysis

Provides insights into customer purchasing behaviour and sales contribution.

### 5. Regional Analysis

Compares sales performance across different regions and locations.

### 6. Interactive Filters

The dashboard includes interactive slicers and filters that allow users to analyse data based on different dimensions such as:

* Date
* Product
* Category
* Region
* Customer

## 🔍 Key Insights

The dashboard helps answer important business questions such as:

* Which products generate the highest sales?
* Which regions perform the best?
* How are sales changing over time?
* Which categories contribute the most to revenue?
* Which products or regions need improvement?
* What are the major sales trends and patterns?
